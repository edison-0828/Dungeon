隐私政策

Cinder Vault / 烬库 · 2026年11月1日

介绍 条款 隐私

这份政策说明 Android 应用 Cinder Vault（包名 com.cindervault.dungeon）如何处理信息。发布者没有另外一套账号系统，也不出售玩家数据。

留在设备上的数据

游戏进度、设置、图鉴和本地排行写在这台设备的应用存储里。发布者的服务器收不到这些内容，因为这只应用没有发布者服务器。

卸载应用会删掉这份本地数据。如果你打开了 Android 备份，系统自己的备份里可能仍留有一份，那由你的系统账号和设备设置决定，不是本应用上传的。

没有注册账号，所以也没有可登录的账号可以删除。要清除本应用持有的数据，卸载即可。

本应用不收集的内容

  • 姓名、邮箱、电话、政府证件号码。
  • 精确地理位置、通讯录、照片、短信。
  • 健康信息、生物识别、银行卡或支付卡号。
  • 广告标识和发布者自建的分析统计。

应用会在设备本地查看网络是否可用、是否按流量计费，以及机型是否为 Solana Mobile 设备，用来决定打赏入口怎么显示。这些判断不上报给发布者。

你主动打赏时会发生什么

只有你在支持页选择打赏，或在选角页向行商购买装备时，应用才会连接钱包和 Solana 网络。不打赏、不购买就不会发生下面这些事。

  • 应用通过 Android 的 Mobile Wallet Adapter 请你的钱包批准连接或一笔转账。钱包把本次会话要用的公钥交给应用。应用不读取助记词或私钥。连接钱包查看购买记录时，应用把这个公钥写在本机设置里，用来对应链上记录。它不会上传到发布者的服务器。
  • 应用向 RPC https://api.mainnet-beta.solana.com 请求最近的区块哈希，并按公钥查询交易，用来确认有没有买过礼包。该节点能看到这些请求来自你的网络。
  • 签名和发送由你的钱包完成。收款地址是 BWfEyAUiSYm7JZ5tVhiUUx3nxmrbZQBLnaiBb1QkyxWV。打赏金额是 0.01、0.05 或 0.1 SOL。行商的装备礼包是 0.05 SOL，转账里带有礼包备注。两种转账都另加网络费。
  • 购买确认后，应用把买下的礼包和交易签名写在这台设备的设置里，用来在之后每一局普通开局时放进背包，并避免同一只钱包重复购买。
  • 交易一旦上链，签名、金额、付款公钥和收款公钥就公开记录在 Solana 上。发布者和任何能浏览区块链的人都能看到这笔交易。应用不能把它删掉。

钱包、RPC 运营方和 Solana 验证者各自有自己的规则。本应用不代替他们做说明。

如果设备上没有兼容钱包，游戏可以打开钱包的下载页，例如 Phantom、Solflare、Backpack、OKX 或 Binance Wallet。只有你选择去安装时才会离开游戏。那些网站不是本应用运营的。

儿童

本应用不面向儿童收集个人信息，也不建立儿童账号。打赏涉及数字资产，请只在你有权使用该钱包时进行。

English

This policy describes how the Android app Cinder Vault, package com.cindervault.dungeon, handles information. The publisher runs no account system and does not sell player data.

Runs, settings, journal progress, and local rankings stay in the app’s storage on your device. The publisher has no server that receives them. Uninstalling the app deletes that local copy. If Android backup is enabled, the operating system may keep a backup under your own device account. That backup is not an upload to the publisher. There is no login account to delete. Uninstalling is how you erase the data this app holds.

The app does not ask for your name, email, phone number, government ID, precise location, contacts, photos, messages, health data, biometrics, or payment-card numbers. It does not use an advertising identifier or a publisher analytics SDK. On the device, it checks whether a network is available, whether that network is metered, and whether the device is a Solana Mobile device, so it can show the tip screen appropriately. Those checks are not reported to the publisher.

A network connection happens only if you choose to tip, to buy a pack, or to connect a wallet and read purchase records. The app asks your installed wallet, through Android’s Mobile Wallet Adapter, to approve the connection or one transfer. The wallet provides the public key for that session. The app does not read your seed phrase or private key. When you connect a wallet to read purchases, the app stores that public key in on-device preferences so it can match the chain record. It does not upload the key to the publisher. It asks https://api.mainnet-beta.solana.com for a recent blockhash and for that wallet’s transactions. That node can see the requests on your network. Your wallet signs and sends a transfer to BWfEyAUiSYm7JZ5tVhiUUx3nxmrbZQBLnaiBb1QkyxWV. A tip is 0.01, 0.05, or 0.1 SOL. The equipment pack is 0.05 SOL and includes a pack memo, plus the network fee. Once confirmed, the signature, amount, memo, and both public keys are public on Solana. The publisher and anyone else browsing the chain can see that transaction, and the app cannot delete it. After confirmation, the app stores the pack and the signature on the device so every new regular run can place the pack in your backpack and the same wallet cannot buy that pack again.

Your wallet, the RPC operator, and Solana validators apply their own rules. If no compatible wallet is installed, the game can open a download page for Phantom, Solflare, Backpack, OKX Wallet, or Binance Wallet. That happens only if you choose to install one. Those sites are not operated by this app.

This app does not collect personal information from children and does not create a children’s account. Send a tip only if you are allowed to use that wallet. Privacy questions: GitHub Issues. Changes to this policy are shown by a new date at the top of this page.
