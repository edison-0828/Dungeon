这是什么

Cinder Vault（烬库）是一款单机地牢探索游戏。关卡、敌人和物品每次开局都会重新生成。不注册账号也能从头玩到通关。

它是 Shattered Pixel Dungeon 的独立修改版，而原作基于 Watabou 的 Pixel Dungeon。本页和这只应用都不是官方版本，也没有得到 Evan Debenham 或 Watabou 的背书。

包名 com.cindervault.dungeon

版本 1.0.0

平台 Android

源码 github.com/edison-0828/Dungeon（GNU GPL v3）

怎么玩

  • 选一个职业，进入随机生成的地牢。
  • 战斗、拾取物品、加深楼层。死亡会结束这一局。
  • 存档、设置和排行都在这台设备上。

可选的 SOL 打赏

玩法不要求钱包。支持页可以自愿打赏 0.01、0.05 或 0.1 SOL。打赏不出售道具、强度或关卡，也不由本应用保管私钥。

确认后，手机会打开你已安装的 Solana 钱包。交易由你在钱包里批准，然后记到 Solana 主网上。收款地址是 BWfEyAUiSYm7JZ5tVhiUUx3nxmrbZQBLnaiBb1QkyxWV。

English

Cinder Vault is a single-player roguelike. You can finish a run without an account and without a wallet. It is an independent modification of Shattered Pixel Dungeon by Evan Debenham, itself based on Pixel Dungeon by Watabou. It is not the official game and is not endorsed by those authors.

Package name com.cindervault.dungeon, version 1.0.0. Source code is published under the GNU GPL v3 at github.com/edison-0828/Dungeon.

An optional support screen can send 0.01, 0.05, or 0.1 SOL. A tip buys no items or power. Your own wallet must approve the transfer, and this app never holds your keys. The recipient address is BWfEyAUiSYm7JZ5tVhiUUx3nxmrbZQBLnaiBb1QkyxWV.
