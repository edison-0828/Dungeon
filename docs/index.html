这是什么

Cinder Vault（烬库）是一款单机地牢探索游戏。关卡、敌人和物品每次开局都会重新生成。不注册账号也能从头玩到通关。

它是 Shattered Pixel Dungeon 的独立修改版，而原作基于 Watabou 的 Pixel Dungeon。本页和这只应用都不是官方版本，也没有得到 Evan Debenham 或 Watabou 的背书。

包名 com.cindervault.dungeon

版本 1.0.1

平台 Android

怎么玩

  • 选一个职业，进入随机生成的地牢。
  • 战斗、拾取物品、加深楼层。死亡会结束这一局。
  • 存档、设置和排行都在这台设备上。

可选的 SOL 打赏

玩法不要求钱包。支持页可以自愿打赏 0.01、0.05 或 0.1 SOL。打赏不出售道具、强度或关卡，也不由本应用保管私钥。

选角页的行商出售一份 0.05 SOL 的装备礼包：+3 短剑、+3 皮甲、+1 命中之戒和 3 把飞刀，开局力量就能装备。每只钱包只能买一次。连接钱包会读取链上记录，买过的不能再买。确认后的礼包会放进之后每一局普通开局的背包，不能由本应用退回。

确认后，手机会打开你已安装的 Solana 钱包。交易由你在钱包里批准，然后记到 Solana 主网上。收款地址是 J9LBv3181d5LojbjebKsrPtLunGQwACayDnXFmLBiwAD。

English

Cinder Vault is a single-player roguelike. You can finish a run without an account and without a wallet. It is an independent modification of Shattered Pixel Dungeon by Evan Debenham, itself based on Pixel Dungeon by Watabou. It is not the official game and is not endorsed by those authors.

Package name com.cindervault.dungeon, version 1.0.1. Source code is published under the GNU GPL v3 at github.com/edison-0828/Dungeon.

An optional support screen can send 0.01, 0.05, or 0.1 SOL. A tip buys no items or power. Your own wallet must approve the transfer, and this app never holds your keys. The recipient address is J9LBv3181d5LojbjebKsrPtLunGQwACayDnXFmLBiwAD.

On the hero select screen, a merchant sells one equipment pack for 0.05 SOL: a +3 shortsword, +3 leather armor, a +1 ring of accuracy, and 3 throwing knives, all usable at starting strength. Each wallet can buy it once. Connecting the wallet reads that record from the chain, and a recorded purchase cannot be bought again. After confirmation, the pack is placed in the backpack of every new regular run. This app cannot reverse that transfer.
